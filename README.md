# Doodle Stroke — 손그림 두들 변환기

마우스나 펜으로 그린 선을, 손으로 두세 번 덧그은 듯한 선으로 바꿔 주는 웹 페이지입니다.

## 여는 법
- **웹**: https://shin-junyeob.github.io/doodle-stroke/ — PC 브라우저(Chrome·Edge 권장)로 바로 씁니다
- **내 PC**: 저장소를 받아 `src/index.html` 을 브라우저로 엽니다(파일 더블클릭). 설치도 서버도 필요 없습니다

그림과 보관함은 각자 브라우저 안에만 저장되고 어디에도 보내지 않습니다.

## 되는 것
- 흰 칸(800×600)에 마우스·펜으로 그리면, 손을 떼는 순간 그 획이 두세 가닥 겹선으로 바뀝니다
  - 모양·위치는 그대로, 둥글게 휘는 곳에서는 가닥이 벌어지고 곧은 변·뾰족한 꼭짓점에서는 붙습니다
  - 열린 선은 끝이 살짝 넘치고, 닫힌 도형은 끝을 시작 쪽에 겹쳐 틈이 없습니다
  - 굵기가 조금씩 흔들리고 끝은 약하게 가늘어집니다
- **지우기**: 칸을 비웁니다
- **PNG 저장**: 흰 배경 PNG(`doodle.png`)로 내려받습니다
- **보관함에 저장** (`Ctrl+S`): 그림을 브라우저 보관함(IndexedDB)에 넣습니다. 불러온 그림을 다시 저장하면 그 항목을 덮어씁니다
  - **보관함 열기**: 썸네일 목록(최신이 위). 패널 바깥을 누르면 접힙니다. 항목마다 **불러오기**(칸에 다시 그려 이어 그리기) · **PNG 받기**(800×600) · **삭제**(두 번 눌러 확인)
  - **내보내기**: 보관함 전체를 `doodle-library-YYYYMMDD.json` 으로 받습니다. **가져오기**: 그 파일을 골라 합칩니다(같은 항목은 덮어씀). 보관함은 브라우저마다 따로라서 옮기거나 백업할 때 씁니다
- **되돌리기** 버튼(`Ctrl+Z`): 마지막 한 획을 뺍니다. 단축키는 버튼에 마우스를 올리면 보이고, 빈 칸 안내에도 적혀 있습니다
- 단축키: `Ctrl+S` 보관함에 저장 · `Ctrl+Z` 한 획 되돌리기 · `Delete` 지우기

- 배경: 연한 회색 바탕에 같은 엔진으로 그린 검은 낙서 무늬(`src/backdrop.js`, 직접 생성 — 바깥 그림 없음)

하지 않는 것: 휴대폰·터치 전용 화면, 색 칠하기, 펜 압력 반영.

## 시험
```
node tests/smoke_browser.mjs        # 브라우저가 뜨는지
node --test tests/engine.test.mjs   # 엔진 모양 판정
node --test tests/browser.test.mjs  # 1 초 안 · PNG 저장
node --test tests/library.test.mjs  # 보관함(저장·새로고침·불러오기·PNG 받기·삭제·내보내기/가져오기)
node --test tests/ui.test.mjs       # 빈 칸 안내 · 단축키 · 가운데 정렬 · 좁은 창
python3 tests/check_license.py      # 바깥 코드·라이선스
```
브라우저 시험은 이미 깔린 Playwright 를 씁니다. 경로가 다르면 `DOODLE_PW`(playwright 모듈 폴더) · `DOODLE_CHROME`(chromium 실행 파일) 환경변수로 지정합니다.

## 라이선스
앱 코드(`src/`)는 직접 작성했고 바깥 라이브러리를 쓰지 않습니다.
